## 6. Rules learned this stretch (all in `knowledge/LESSONS-NCINO-APEX.md` 8o and 8p, backlog rows 63 to 75)

- Any execute that can wake nCino's renewal or credit-action engine (chain rows, rolls, renewals) takes
  the relay door. Created-package discards passed only because they had no chain rows.
- A hosted MCP hop is a shared resource: one page, one in-flight read per question; writes never queue
  behind reads; the same idempotency key on every leg.
- Nothing on the glass claims a state Boom does not report (four words: processing, completed,
  verified, failed). The ghost is the file's text, the register is Boom's, the reconciliation is
  derived, never authored.
- The gate runs alone; a harness crash is retried once and never read as a room finding.
- Design changes go through the intent gate with ONE rendered option from real data; the founder
  delegated taste on 16 Sep ("just do it, i trust your taste now") but rejected 0.9.31's reading beat
  as flat, so render before build even when delegated.
