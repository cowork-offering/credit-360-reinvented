Release = four steps, in order:
1. `cd app && npm run build` (vite → dist, then `rename-bundle.mjs`)
2. `node scripts/release-artifact.mjs` (promotes dist/cockpit.html → `artifact/customer-360-template.html`, marker verified)
3. `node scripts/assemble-artifact.mjs` (injects `artifact/live-data.json` into the template's data slot → `/tmp/c360-publish.html`)
4. Artifact tool publish to BOTH URLs (copy the file for the second one — the tool needs distinct paths per URL)

**HARD LESSON (cost 3 broken publishes on 2026-07-27):** never inject data by replacing the
`/*__C360_DATA__*/` comment marker ad hoc — the compiled bundle contains that literal inside its own JS
(load.ts PLACEHOLDER), and a first-occurrence replace puts the JSON into code and ships "No data injected".
`assemble-artifact.mjs` matches the FULL `<script id="c360-data">` tag, asserts it unique, and re-parses the
slot before exiting. Use it, always.

QA gate before any publish: `npm run typecheck`, `npx vitest run` (currently 1079), contrast check 31/31,
clean-room `npm ci` pass. The builder agent reports these; verify numbers, don't trust prose.

## 6. Cockpit architecture (app/src)

- **Data**: baked bundle (`artifact/live-data.json`, 5 borrowers: Hartwell, Piedmont + 3 samples) injected at
  assembly; **Sync sweep** (`channel/syncSweep.ts`) overlays live reads for the OPEN account. Overlay now
  **persists to localStorage** per account (version-keyed, restored with true storedAt age; staging tokens
  and plans are NEVER persisted — tested). Cache tiers: graph + covenants are slow-moving (5-min window, not
  called inside it); exposure/snapshot/signals/opportunities/history/mail fetch every sync. Pacing ≤2
  concurrent, 200ms gaps; retry-once lives in `callTool` (reads only, stamped-retryable only — do NOT add a
  second retry in the sweep).
- **Channel** (`channel/mcp.ts`, `cockpitTools.ts`, `writeTools.ts`): window.claude.mcp seam; transport vs
  domain error split; execute payload key set pinned by test; `unwrapMail` handles array/wrapper/bare
  object/JSON string/JSONL + drops pagination tails; MailHit maps preview from `summary` first, sender from
  string or Graph object.
- **Mail → action** (`c3b284d`): deterministic extraction (intent verbs, money incl. "15Mio"/"$15MM"/"750k",
  facility fuzzy-match against REAL booked facilities incl. disambiguation by amount when two facilities
  share a type). Readable request → ClientRequest → suggestion on the mail activity entry → opens the
  modification ticket prefilled with CLIENT_REQUEST provenance. Ambiguous → honest degraded card, no guessed
  numbers. Never auto-stages.
- **Deal tickets** (`actions/`): package-centric mod/renewal (package subject card, facility multi-select
  inside the package), collateral valuation with selection step over deduped collateral records + TRUE bulk
  (items[] on the observed envelope; one plan, one token; per-item Filed rows), review fork (Credit vs Risk
  Rating, explicitly distinct; risk-rating has NO facility scope by org precedent; credit-review loan-scope
  selector NOT built — pending the invoker redesign), new-facility names the package it joins.
  Registry availability speaks package language via `bookedFacilityAvailability`.
- **Aggregation invariants** (graphAggregate + friends): one row per counterpartyId, specific role beats
  generic mirror (Company/Child), largest percent across the pair, Related-parties section for connections
  the ownership tree can't place, aggregate-by-identity on EVERY per-involvement list (signals included).
  **Per-borrower test matrix** mounts every fixed surface for all 5 borrowers in BOTH data files.
- **Grounded chat**: prose-only prompts, ≤600 chars, sanitize() strips braces/pipes/long ids — this is the
  trust-budget discipline (see §8).

## 8. Platform truths (hard-won, don't relearn)

- **Trust budget**: claude.ai gives a page session a per-connector budget burned by call VOLUME and
  machine-shaped PAYLOADS. Symptom: `blocked_by_policy`, misleading "organisation's policy" copy.
  Per-connector, page-scoped, self-expiring (reload/wait heals). Mitigations shipped: prose-only prompts,
  paced sweep, cache tiers. Residual line failures during rapid repeated Syncs are THIS, not our bugs.
- **Wire observation is law**: `@InvocableVariable(required=true)` is enforced by the REST Actions API but
  NOT by direct Apex test calls — a 141/141-green tool was unusable on the wire (lesson 16aa). Any tool
  gaining an alternative input shape must drop required=true and enforce in Apex. Never pin a cockpit wire
  shape without a verbatim observed envelope (archive: `/tmp/wave2-envelopes.json`, keys incl.
  `package_first_new_facility`, `bulk_collateral_valuation`).
- **M365 envelope**: single result = ONE BARE OBJECT (not array); preview field is `summary`; sender can be
  plain string; pagination tail rows carry nextOffset/nextCursor. Observed live 2026-07-27.
- **Actions API path** uses the Apex CLASS name (`/actions/custom/apex/StageCollateralValuation`), not the
  MCP tool name.
- **Two-invocation resume** for new facility: after-commit async flow invisible to inserting transaction;
  never spin-wait in Apex.
- **CreateCreditReviewInvoker** (probe wave 7, CLEAN): nCino's managed action takes `loanIds` as List<Id>
  (describe lies and says scalar), sets Review_Loan lookups directly, no human-facing side effects observed,
  returns reviewIds; but it doesn't set Is_Agentic_Review or Product_Package, and using it requires opening
  the allowlist NARROWLY for post-create update on the review it just returned. Redesign approved,
  probe-gated, NOT yet built.
- Org rewrites Loan Name + Package Name on insert; Metadata API grants FLS to nobody; record-type picklist
  scoping isn't API-enforced; collateral rollup never fires headlessly (valuations don't move collateral value).
