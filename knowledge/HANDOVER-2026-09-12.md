## 8. Gotchas that cost time today (do not repeat)
- The PreToolUse bash hook blocks metacharacters (`[ ] { } ? * $`, quotes) in tokens near protected
  stems and blocks `~`/globs on memory paths: use literal paths, `Read` for memory files, write commit
  messages to a scratch file and `git commit -F`. The word "contradictions" in a commit body trips it.
- `npm run build | tail` masks the gate's exit code. Use `if npm run build; then …`.
- rg/grep output mangles some identifiers in this terminal; confirm tokens via Read/sed.
- Artifact code is frozen at publish: a plugin update never changes an already-published cockpit;
  Fabian must re-open from the new plugin (and the stale canonical URL can resurrect the old one).
- The workroom does NOT depend on the IDB Gateway for its brain; it is session-Claude-first. I asserted
  the opposite twice today from a stale memory note. Verify in code before asserting.
- The "Approval closed" finale message is the cockpit's governance closing after a failed filing
